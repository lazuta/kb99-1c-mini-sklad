# Мини-Склад

Конфигурация для платформы 1С.

## Состав конфигурации

| Объект | Описание |
|---|---|
| **Подсистемы** | |
| `МиниСклад` | Интерфейс складского учёта |
| **Справочники** | |
| `Товары` | Номенклатура товаров |
| `Контрагенты` | Поставщики и покупатели |
| **Документы** | |
| `Поступление` | Приход товаров |
| `Реализация` | Продажа и списание товаров |
| **Регистры накопления** | |
| `ОстаткиТоваров` | Учёт остатков товаров |
| **Формы** | |
| `Поступление.ФормаДокумента` | Форма поступления |
| `Реализация.ФормаДокумента` | Форма реализации |

## Дополнительные реализации

| Функциональность | Описание |
|---|---|
| Автоматический расчёт суммы | Количество * Цена |
| Проверка количества | Запрет нулевого и отрицательного количества |
| Контроль остатков | Запрет реализации при недостатке товара |
| Валидация телефона | Маска `+375(XX)XXX-XX-XX`, проверка кодов 29, 33, 44 |
| Выбор единиц измерения | Ссылочный реквизит с выбором из справочника |

## Запуск проекта

1. Установить **1С:Предприятие 8.5** (совместимую версию платформы).
2. Клонировать репозиторий:

   ```bash
   git clone https://github.com/lazuta/kb99-1c-mini-sklad
   ```

3. Создать [пустую файловую информационную базу](hhttps://its.1c.ru/db/pubdevguide83/content/17/hdoc), следуя официальной инструкции 1С.
4. Открыть **Конфигуратор → Конфигурация → Загрузить конфигурацию из файлов** и выбрать каталог `configuration/` из клонированного репозитория.
5. Обновить конфигурацию базы данных (**F7**).
6. Запустить базу в режиме **1С:Предприятие**.

После запуска открыть подсистему **«Мини-Склад»**.
